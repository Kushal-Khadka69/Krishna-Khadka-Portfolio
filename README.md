# Krishna Khadka Portfolio

A personal portfolio website built with Django to showcase video editing, graphic design, and creative work.

## Overview

This project is a modern portfolio for Krishna Khadka, featuring:

- Hero section with profile intro
- About section
- Skills section with tool branding
- Project gallery for videos and graphics
- Testimonials section
- Contact form
- Social media links and footer

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript

## Features

- Responsive dark-themed portfolio layout
- Video and image gallery cards
- Smooth skill card loading animations
- Social media branding with custom gradients
- Contact form for portfolio inquiries

## Setup Instructions

1. Clone the repository

```bash
git clone https://github.com/Kushal-Khadka69/Krishna-Khadka-Portfolio.git
```

2. Navigate to the project folder

```bash
cd Krishna-Khadka-Portfolio
```

3. Create a virtual environment

```bash
python -m venv venv
```

4. Activate the virtual environment

On Windows:

```bash
venv\Scripts\activate
```

On macOS/Linux:

```bash
source venv/bin/activate
```

5. Install dependencies

```bash
pip install django
```

6. Run the development server

```bash
python manage.py runserver
```

7. Open the project in your browser

```bash
http://127.0.0.1:8000/
```
